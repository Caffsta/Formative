######Data summary ######

##### BMI data

There are 9951 rows to this dataset, 9950 participants as one row is a header row. The file is comma seperated and saved as a CSV. 

There are 28 columns in this dataset containg a ID row, sequence number and BMI columns. All rows have 28 columns after checking this. 

##### Accelerometer data

There are 7455 accelerometer files with name accel-*.txt, they are tab seperated with the participant number in the text for name. 

There are 8 columns in the first two datasets, with some rows in a couple of files that have three columns populated.
